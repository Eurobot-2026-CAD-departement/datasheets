# Datasheets

Datasheets and dimension drawings of components used on the robots.

- Pololu 37D metal gearmotors (datasheet + dimension diagram)
- JGB37-550 180 rpm geared motor
- Pololu ball caster (0.375 in ball)
- MWE31 encoder + support
- AMS1117 voltage regulator (for the ESP32)

These documents belong to their respective manufacturers and are included for reference.
